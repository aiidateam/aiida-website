We just released a new patch version of AiiDA, v2.7.4.

It fixes a SQLite `QueryBuilder` regression where filters such as `{'ctime': {'in': [...]}}` or `{'ctime': {'!in': [...]}}` with Python `datetime` values could fail ([#7486](https://github.com/aiidateam/aiida-core/pull/7486)).
Plugins that select or exclude nodes by creation or modification time work again on SQLite profiles.
It also adds a migration that downgrades a version 10 configuration schema, introduced in the upcoming v2.9.0, back to the version 9 schema used by the 2.7 series ([#7417](https://github.com/aiidateam/aiida-core/pull/7417)), so you can try out v2.9.0 and come back without fixing up `config.json` by hand.

The same fixes went out today for the 2.8 series in [v2.8.1](https://aiida.net/blog/2026-07-25-release-281/).

You can find the full list of changes in the [CHANGELOG](https://github.com/aiidateam/aiida-core/blob/v2.7.4/CHANGELOG.md#v274---2026-07-25).

Happy computing!

The AiiDA team
