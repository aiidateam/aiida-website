We just released a new patch version of AiiDA, v2.9.2.

It fixes an error triggered when a `BaseRestartWorkChain` runs with `clean_workdir` enabled ([#7593](https://github.com/aiidateam/aiida-core/pull/7593)).
The cleanup runs while the process transitions to its terminal state, and on that code path the greenback portal that the asynchronous transports rely on was never opened, so the work chain raised a `RuntimeError` right at the end instead of finishing.
It affects work chains submitted to the daemon that use the `core.ssh_async` transport.

The same fix went out today for the 2.8 series in [v2.8.3](https://aiida.net/blog/2026-09-03-release-283/).

You can find the full list of changes in the [CHANGELOG](https://github.com/aiidateam/aiida-core/blob/v2.9.2/CHANGELOG.md#v292---2026-09-03).

Happy computing!
