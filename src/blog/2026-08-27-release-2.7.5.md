We just released a new patch version of AiiDA, v2.7.5.

`verdi process dump` silently omitted repository files from output data types that had no `SinglefileData` or `FolderData` sibling, and now writes the files of all repository-backed outputs ([#7525](https://github.com/aiidateam/aiida-core/pull/7525)).
A failed `COPY` stash also deleted the sibling stashes that happened to share the same UUID shard, which could remove unrelated stashed data ([#7563](https://github.com/aiidateam/aiida-core/pull/7563)).
If you use stashing, we recommend upgrading.

Both fixes went out today for the other maintained series as well, in [v2.8.2](https://aiida.net/blog/2026-08-27-release-282/) and [v2.9.1](https://aiida.net/blog/2026-08-27-release-291/).

You can find the full list of changes in the [CHANGELOG](https://github.com/aiidateam/aiida-core/blob/v2.7.5/CHANGELOG.md#v275---2026-08-27).

Happy computing!

The AiiDA team
